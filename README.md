# Lorem Ipsum — Bank homepage concept

A homepage design concept for a fictional bank, "Lorem Ipsum". It has a hero
text animation, scroll animations and a phone/tablet layout. No build step:
`index.html` renders with `support.js`; images are in `_blob/`.

Run locally: `python3 -m http.server` in this folder, then open http://localhost:8000.

The bank, its products, offers, news and phone numbers are made up for design
review. The page is not affiliated with any real bank.
